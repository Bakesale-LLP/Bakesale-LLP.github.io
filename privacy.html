Privacy Policy

Effective 24 September 2026

This policy covers the one place Bakesale POS connects to a Google account: the optional Google Drive Backup feature in its Admin Panel. Nothing here applies unless a shop's admin deliberately connects a Google account to that feature.

What access we ask for

Bakesale POS requests the drive.file scope only. Under this scope, the app can see, create and manage only the backup file it creates itself. It cannot view, open, edit or delete anything else in your Drive.

We also read the connected account's email address so the Admin Panel can show which account is linked. We do not request access to Gmail, Contacts, Calendar or any other Google service.

What we do with it

  • Once an hour, the shop's own server uploads a single JSON backup file to a folder named "Bakesale Backup" in the connected Drive account, replacing the previous hour's file.
  • An admin can trigger this manually with "Test Upload Now", or stop it entirely with "Disconnect".

Where your data lives

The backup file is stored only inside the connected Google Drive account. We do not keep a copy on any server of ours. The shop's own server stores the OAuth token needed to keep uploading, and the connected account's email address, for as long as the feature stays connected.

Sharing

We do not sell this data, share it with third parties, or use it for advertising. It exists solely to operate the backup feature described above.

Revoking access

Disconnect any time from the Admin Panel, which deletes the stored token immediately. You can also revoke access from your Google Account's Third-party apps & services page.

Google API Services User Data Policy

Bakesale POS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
